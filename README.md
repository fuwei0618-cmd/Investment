# 投資羅盤

依個人課程架構整合的投資工具（網頁版，手機也能用）。主選單照「由上而下」的決策流程排列：

1. 財務目標（王伯達 人生財務規劃學）✅
2. 風險屬性（CodeGym 1-2、王伯達 4 章）
3. 總經羅盤（M平方 總經、總經X產業X個股）✅
4. 產業雷達（總經X產業X個股 3 章）
5. 個股研究（總經X產業X個股 4 章、CodeGym 3、4 章）
6. 量化與技術（CodeGym 5 章）
7. 持股與損益（王伯達 4 章、CodeGym 6、9 章）✅
8. 日誌與情緒（CodeGym 7、8 章）
9. AI 助理（AI Agent 投資系統實戰課，尚未上架）

## 開發

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 計算邏輯單元測試
```

## 環境變數（選填，部署到 Vercel 時在專案設定加入）

| 名稱 | 用途 |
|---|---|
| `FMP_API_KEY` | 美股報價（Financial Modeling Prep，免費每天 250 次） |
| `FINMIND_TOKEN` | 台股報價額度提高（不設也能用） |

總經指標來自 FRED 公開資料，不需金鑰。持股與試算資料只存在使用者瀏覽器。
